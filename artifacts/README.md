Provenance: all files were copied (`cp -p`) from the working tree of the
underlying study on 2026-11-15; the mapping below records the original
location of each file. FACTS.md cites these paths + key paths; FACTS.md
itself is generated by `scripts/build_facts.py` from these files (so the
table cannot drift from the data).

## z3_classes/

`{kn_n3,kn_n4,kn_n5,kpn_n4,kpn_n5,mirror_n4,both_n4}/`:
`z3_injectivity.json` (basis v1 result: REFUTED, with the certified
